# Utilities

General-purpose utility functions and helpers used throughout the Irmin platform. Provides common functionality for data processing, validation, formatting, and system operations.

## Purpose

Provides utility functions for:

- **Data Processing**: Parsing, validation, and transformation utilities
- **File Operations**: Path handling, content type detection, and file processing
- **HTTP Utilities**: Request/response handling, multipart data, and headers
- **Security**: JWT validation, random string generation, and secure identifiers
- **System Operations**: Environment loading, project discovery, and configuration
- **Query Processing**: SQL parsing and workspace-specific query handling

## Integration

Used throughout the platform by:

- **Controllers** for request processing and validation
- **Engine** for data processing and file operations
- **Database** for configuration and environment management
- **Authentication** for security and validation
- **Orchestrator** for query processing and system operations
