# Database Models

Database layer providing GORM models, database operations, and data persistence for the Irmin platform. Defines schema, relationships, and data access patterns.

## Features

- **GORM Integration**: Modern ORM with automatic migrations
- **Relationship Management**: Proper foreign keys and associations
- **Data Validation**: Model-level validation and constraints
- **Audit Logging**: Automatic tracking of data changes
- **Search Integration**: Full-text search capabilities
- **Migration Support**: Database schema versioning and updates

## Database Operations

- **CRUD Operations**: Standard create, read, update, delete operations
- **Complex Queries**: Advanced querying with joins and aggregations
- **Transaction Support**: Multi-operation transactions for data consistency
- **Connection Pooling**: Efficient database connection management
- **Notification System**: PostgreSQL LISTEN/NOTIFY for real-time updates
