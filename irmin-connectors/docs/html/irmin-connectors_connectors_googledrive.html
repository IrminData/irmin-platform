Package irmin-connectors/connectors/googledrive

package googledriveconnector // import "irmin-connectors/connectors/googledrive"

Package googledriveconnector wires the Google Drive connector's controllers into
the shared HTTP router. Call SetupRoutes once at startup; every request flows
through common.SetupConnectorRoutes from there.

FUNCTIONS

func SetupRoutes(app *models.ConnectorsApp)
    SetupRoutes mounts the Google Drive connector under /googledrive.
    The controller embeds *common.OAuthConnector so every operation inherits the
    OAuth machinery without per-route wiring.
