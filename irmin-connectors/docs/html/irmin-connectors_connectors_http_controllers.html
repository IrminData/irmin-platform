type Controllers struct {
	*common.Controllers
	*common.OAuthConnector
}
    Controllers holds the dependencies for the HTTP connector controllers.

    OAuthConnector is embedded even though HTTP is a static-credential
    connector. The base no-ops cleanly when Config is nil (Info stamping skips,
    resolver returns ErrOAuthNotConfigured), which keeps the embed uniform
    across the connector family. This is the "prove the base handles the
    non-OAuth case" step from Phase 3: HTTP reuses the shared scaffolding
    without adopting OAuth itself.

	ctx context.Context,
	logger *slog.Logger,
	operation *db.Operation,
) (any, *string, func(), error)
    InitializeClient initializes the HTTP client for pull operations.

func (p *HTTPPullProvider) ProgressHandler(_ *db.Operation) common.ProgressHandler
    ProgressHandler returns nil — a single HTTP request bounded by the
    configured timeout (default 300s) can't produce a meaningful silent-window
    incident, and the common pull handler's baseline heartbeat covers what
    little exposure remains.
