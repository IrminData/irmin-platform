Package irmin-connectors/connectors/linear

package linearconnector // import "irmin-connectors/connectors/linear"

Package linearconnector wires the Linear connector's controllers into the shared
HTTP router. Call SetupRoutes once at startup; every request flows through
common.SetupConnectorRoutes from there.

    SetupRoutes mounts the Linear connector under /linear. The controller embeds
