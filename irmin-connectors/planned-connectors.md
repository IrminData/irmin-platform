# Planned Connectors

This document outlines the connectors we're planning to build for the Irmin ecosystem, organized by category.

## Currently Available
- **PostgreSQL** ✅ - Complete database integration with real-time subscriptions

## In Development Pipeline

### MCP Server Connector 🔄
**Description**: Interact with Model Context Protocol (MCP) servers through Irmin
**Use Cases**:
- Connect to AI model context providers
- Integrate with language model services
- Synchronize context data across AI workflows
