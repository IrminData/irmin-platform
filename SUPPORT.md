# Support

Use GitHub issues for reproducible defects and focused feature requests once
the repository is opened for community participation.

Before filing:

1. Search existing issues.
2. Identify the affected project and revision.
3. Include minimal reproduction steps, logs with secrets removed, and relevant
   environment information.

Questions about managed deployments, accounts, private infrastructure, or
security vulnerabilities should use the appropriate private Irmin support
channel. Security reports must follow SECURITY.md.
