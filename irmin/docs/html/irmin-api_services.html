    associated user. It supports system token, credentials token (cred_ prefix),
    and JWT from Clerk. Uses caching to avoid expensive validation and sync
    operations for recently authenticated tokens. External API operations
    (Clerk/Novu sync) happen asynchronously in the background. Returns: user,
    isSystem, error
