# Code of conduct

Irmin contributors must help maintain a respectful, constructive, and
professional community.

## Expected behavior

- Discuss ideas and code without personal attacks.
- Give actionable feedback and assume good intent while still protecting
  technical quality and user safety.
- Respect differing experience, identity, background, and communication style.
- Keep private reports, credentials, and personal information confidential.
- Accept maintainers' decisions about scope, moderation, and repository safety.

## Unacceptable behavior

Harassment, threats, discrimination, sexualized conduct, doxxing, sustained
disruption, or publishing another person's private information is not allowed.

## Enforcement

Report conduct concerns privately to the maintainers. Maintainers may edit or
remove content, close participation, temporarily restrict access, or
permanently ban contributors when necessary. Reports will be handled as
confidentially as practical.

This policy applies in repository discussions and in public spaces where a
person is representing the Irmin project.
