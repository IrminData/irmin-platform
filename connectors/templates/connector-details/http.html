Connection Setup

Steps for establishing the HTTP connection:

  • URL Configuration: Specify the target HTTP endpoint URL where data will be sent or retrieved from.
  • Authentication: Configure authentication methods including API keys, basic auth, or custom headers.
  • Headers: Set custom HTTP headers for requests, including Content-Type, User-Agent, and authorization headers.

Data Operations

HTTP connector supports the following operations:

  • Pull: Makes a GET request to the configured URL and returns the response as a downloadable file. Supports various response formats including JSON, XML, CSV, and binary data.
  • Push: Sends the provided file content as the request body to the configured endpoint using POST, PUT, or PATCH methods. Supports various content types and custom headers.

Supported Features

  • Multiple HTTP Methods: GET, POST, PUT, PATCH, DELETE
  • Custom Headers: Add any custom HTTP headers for authentication or API requirements
  • Content Types: Support for JSON, XML, CSV, plain text, and binary data
  • Authentication: API keys, basic authentication, bearer tokens, and custom header-based auth
  • Error Handling: Proper HTTP status code handling and error reporting
