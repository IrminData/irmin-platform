Connection Setup

Steps for establishing the connection:

  • API Key: Your Pinecone API key for authentication. Found in the Pinecone console.
  • Index Host: The host URL for your Pinecone index (e.g., index-name-abc123.svc.us-east-1.pinecone.io).
  • Namespace: Optional namespace to target within the index. Leave empty for the default namespace.

Data Operations

Data movement operations are implemented as follows:

  • Push: Upload embedding vectors from Irmin's parquet format to Pinecone. Vectors are upserted in batches of 100 for optimal performance.
  • Pull (Search): When a query vector is provided, performs semantic search and returns JSON results with similarity scores.
  • Pull (Export): When no query is provided, exports all vectors from the index/namespace as a parquet file compatible with Irmin's embedding format.

Data Format

The connector maps between Irmin's embedding format and Pinecone vectors:

  • id → Vector ID
  • embedding → Vector values (float32 array)
  • content → Stored as metadata
  • source_file → Stored as metadata
  • chunk_index → Stored as metadata
  • metadata → Flattened into Pinecone metadata
