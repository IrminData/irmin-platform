Connection Setup

Steps for establishing the Firecrawl connection:

  • API Key: Obtain your API key from firecrawl.dev and enter it in the configuration.
  • Operation Type: Choose the type of operation: scrape, crawl, map, or search.
  • Target URL: Specify the URL to scrape, crawl, or map (required for non-search operations).
  • Output Format: Select your preferred output format: Markdown, HTML, or JSON with metadata.

Available Operations

Scrape

Extract content from a single URL. Returns clean markdown, HTML, or JSON representation of the page content. Ideal for extracting specific pages or articles.

Crawl

Automatically discover and extract content from a URL and all its accessible subpages. Perfect for converting entire websites into structured data. Configure limits to control the scope.

Map

Quickly discover all URLs from a website without extracting content. Returns a JSON file containing all discovered links. Useful for site audits and understanding website structure.

Search

Search the web and get full content from search results. Enter a search query and receive extracted content from the top results.

Output Formats

  • Markdown (.md): Clean, readable markdown format ideal for documentation and LLM applications.
  • HTML (.html): Full HTML content for web applications and detailed analysis.
  • JSON (.json): Structured JSON with content, metadata, and extracted links for programmatic use.

Key Features

  • LLM-Ready Output: Content is automatically cleaned and formatted for use with AI/LLM applications.
  • Metadata Extraction: Automatically extracts title, description, Open Graph tags, and other metadata.
  • Link Discovery: Discovers and returns all links found on scraped pages.
  • No Sitemap Required: Intelligent crawling that works without requiring a sitemap.
  • Configurable Limits: Control the scope of crawl operations with page limits.
