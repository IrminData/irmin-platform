Irmin SDK context
- Context: All API calls require `context.Context` as first parameter. Use `context.Background()` at start of main()
- Core API client: `irmincore.NewClient(apiURL, apiKey, "en")`
- Input handling: `irminutils.ListInputFiles()`, `irminutils.GetInputFile(filename)`
- Output handling: `irminutils.SendComputeResult(content, filename)`
- API flags: `irminutils.GetAPIFromFlags()` returns (apiURL, apiKey, error)
- Available operations: repositories, refs, objects, workflows, compute results

SQL and DuckDB in scripts
- Scripts can execute SQL queries against Irmin repositories using the SDK
- All SQL queries follow the same rules as interactive queries:
  - Use Irmin placeholders: $["workspace;repository;object@ref"]
  - Write operations supported: COPY TO, CREATE TEMPORARY TABLE/VIEW, INSERT/UPDATE/DELETE on temp tables
  - Security constraints: Only TEMPORARY tables/views; blacklisted commands (ATTACH, CREATE SECRET, INSTALL, EXPORT DATABASE) will fail
  - Permission checks: Write operations require write permissions on target repositories
- To execute queries in scripts, use the appropriate SDK methods for query execution
- Best practices: Use COPY TO to export processed results back to LakeFS repositories

**Example outputs (format only):**  

- Go‑only:  
```go
package main

import (
	"context"
	"log"
	irmincore "github.com/IrminData/irmin-sdk-go/api"
	irminutils "github.com/IrminData/irmin-sdk-go/utils"
)

func main() {
	// Create context for API calls.
	ctx := context.Background()
	
	// Parse API flags.
	apiURL, apiKey, err := irminutils.GetAPIFromFlags()
	if err != nil {
		log.Fatalf("Error getting API flags: %v", err)
	}

	// Initialise the Irmin API client.
	client := irmincore.NewClient(apiURL, apiKey, "en")

	// List available workspaces.
	workspaces, _, listWorkspacesErr := client.ListWorkspaces(ctx)
	if listWorkspacesErr != nil {
		log.Fatalf("Error listing workspaces: %v", listWorkspacesErr)
	}
	if len(workspaces) == 0 {
		log.Fatal("No workspaces found")
	}

	// Print the workspace names.
	for _, workspace := range workspaces {
		println(workspace.Name)
	}

	// Get input files.
	inputFiles, err := irminutils.ListInputFiles()
	if err != nil {
		log.Fatalf("Error listing input files: %v", err)
	}

	// Echo input files back as results.
	for _, f := range inputFiles {
		content, err := irminutils.GetInputFile(f)
		if err != nil {
			log.Fatalf("Error reading input file %s: %v", f, err)
		}
		if sendErr := irminutils.SendComputeResult(content, f); sendErr != nil {
			log.Fatalf("Error sending result: %v", sendErr)
		}
	}
}
```
